# Maintainers

## Primary maintainer

- Sebastian Legarraga ([@slegarraga](https://github.com/slegarraga))

## Maintainer responsibilities

- Review issues and pull requests.
- Maintain releases and npm package publishing.
- Keep error-shape fixtures current for OpenAI, Anthropic, Gemini and compatible APIs.
- Triage compatibility, security and documentation reports.

## Scope

`llm-errors` is maintained as a public MIT package for provider-portable error
classification and retry handling. The primary maintainer controls the GitHub
repository, npm package, release tags and security policy.
